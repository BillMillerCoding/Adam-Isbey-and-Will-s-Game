# The Final Boss
A Game by Adam Hill, Isbey, and William Miller

# How To Play on Windows
  - Download finalboss.zip
  - Extract it using your preferred software
  - Then run The_Final_Boss.exe located among the extracted files
  - Enjoy!
# How To Play on Mac
  - Download FinalBossMac.zip
  - Extract it
  - Run FinalBoss.dmg among the extracted files
  - Enjoy!
